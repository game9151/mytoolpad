Free strong password generator

Generate a secure random password in one click. Choose the length and whether to include uppercase letters, numbers and symbols. Passwords are created in your browser with the Web Crypto API and are never stored or sent anywhere.

Length matters most: each extra character multiplies the number of possible passwords. Aim for at least 14–16 characters and use a different password for every account.

How to use it

  1. Set the length with the slider.
  2. Choose which character types to include.
  3. Copy the password and store it in a password manager.

Frequently asked questions

How long should a password be?

At least 14–16 characters for important accounts. Longer random passwords are far harder to crack than short complex ones.

Is this generator safe?

Passwords are generated locally using your browser’s cryptographically secure random number generator and are not transmitted or logged.

Should I reuse passwords?

No. Use a unique password for each account and keep them in a password manager.
